# Inputs from the NL-02 study

The files in this folder are copied unchanged from the NL-02 study (archive: https://doi.org/10.5281/zenodo.23444562, folder
`studies/nl02/`), so that the N1 scripts in this archive run from this folder alone. They are inputs here;
to regenerate them, run the listed script in the NL-02 archive.

| File | Role | Generated in the NL-02 archive by |
|---|---|---|
| `hw_scan_wg.json` | input data | `studies/nl02/hw_scan.py` |
| `model3.py` | module imported by the N1 scripts | (source) |
| `numbers.json` | input data | `studies/nl02/collect_numbers.py` |
| `qwkit_validation.json` | input data | `studies/nl02/qwkit_validation.py` |
| `qwkit_validation.py` | module imported by the N1 scripts | (source) |
